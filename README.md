## 🔒 100% 本機離線儲存 (完全免註冊)

* **資料存哪裡？** 
  所有自訂課表、組數紀錄、個人 PR 都 **100% 保存在你的手機瀏覽器（LocalStorage）**，沒有任何後端伺服器，你的訓練數據完全屬於你自己。
* **健身房沒訊號？** 
  地下室沒網路照常秒開、順暢打勾。
* **換手機怎麼辦？** 
  在「數據分析」分頁點 **「匯出備份 (JSON)」** 存檔，換手機後點 **「匯入還原」** 就能一秒轉移！

## 📱 手機「加入主畫面」（像原生 App 一樣全螢幕）

1. 用手機打開網址：`https://411385027Jimmy.github.io/ironlog/`
2. **iPhone (Safari)**：點瀏覽器下方「分享」圖示（帶向上箭頭 ⎋）➔ 點選 **「加入主畫面」**。
3. **Android (Chrome)**：點右上角選單（三個直點 ⋮）➔ 點選 **「安裝應用程式」** 或 **「新增至主螢幕」**。
4. 桌面就會出現 **IronLog** 圖標，點開就是全螢幕，沒有任何網址列干擾！

## 🚀 3 步極簡上手指南

### 第一步：排定你的課表（課表排程）
* 點底部 **「課表排程」**：
  * **每週排程**：點週一至週日的按鈕，指定那天要練「推」、「拉」、「腿」或「休」。
  * **自訂課表**：可自訂動作與順序，想練什麼動作**直接打字就能新增**！還有「一鍵複製」功能方便建置推 A / 推 B。

### 第二步：進健身房開練（現場訓練）
* 點底部 **「現場訓練」**：
  * 系統會根據今天排程自動載入課表（今天是休就會乾淨顯示休息日）。
  * **點擊前次紀錄（淡灰字體）**：一秒自動帶入上次做過的重量與次數！
  * 做完一組點右邊綠色 **「✓」** 打勾完成；手滑按錯**再點一次就能取消**。
  * 旁邊有 `+1.25`、`+2.5`、`+5` 微調鍵與 `同上` 按鈕，單手就能完成輸入，不用一直叫出手機鍵盤。
  * 頂部有手動計時器，點一下開始倒數，時間到會發出嗶嗶聲與震動。

### 第三步：歸檔與看成果（數據分析）
* 全部練完點底部 **「完成今日訓練（歸檔）」**：
  * 自動產生一張超帥的**黑底硬派結算海報圖卡**，可直接下載分享到 IG 或 LINE！
* 切換到 **「數據分析」**：
  * 查看像 GitHub 一樣的 **訓練日曆熱圖**。
  * 查看 **SVG 人體肌群疲勞圖**（紅=剛練完疲勞、綠=充分恢復）。
  * 誤觸或測試的紀錄隨時可單筆刪除，也可一鍵清空歸零。

## 💡 現場超實用小功能

* **動作指南與示範 (Exercise Guide)**：點擊動作卡片上的「指南」或動作名稱，即刻展開 40+ 主流動作標準教學（【預備姿勢】、【動作過程與節奏】、【關鍵發力、代償地雷與呼吸原則】），自訂動作亦有智慧肌群防呆指引！
* **Form Check 側拍影片回放 (Video Player)**：點擊卡片右上角「側拍 / 影片」，可直接選取手機相簿/本機側拍影片（透過 IndexedDB 離線安全保存，不佔雲端空間）或外部直連 URL，動作卡片相機圖示自動亮綠燈；下方更提供「個人發力要訣備忘 (Form Cue Notes)」，跨課表永久綁定！
* **常駐備忘錄 (Pin Note)**：每個動作頂部可寫一行筆記（例如：*椅背第 3 孔、握距壓紋、史密斯空槓10kg*），永久保存。
* **複合動作熱身組**：深蹲、臥推輸入正式重量後，點卡片上的「熱身」，自動幫你排出 3~4 組階梯遞增熱身組。
* **計算工具箱**：頂部計算機圖示點開，可速查 1RM/次數配重表、雙重超負荷診斷、以及每日蛋白質攝取量。
* **器械被佔臨時替換**：點卡片右上角「替換」，一秒換成同部位啞鈴或機械，不影響原課表。
* **不鎖死自由訓練**：歸檔後隨時可繼續加組加練，系統將即時覆蓋更新當日歸檔，彈性十足！
