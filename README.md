# IronLog Pro 🏋️‍♂️ 極簡高強度重訓工作表 (PWA)

> 靈感源自 **Hevy Pro** 與 **Fitbod** 的純前端健身輔助工具。
> 專注於極致乾淨的訓練工作表（Workout Sheet）、打勾完成流、肌群疲勞恢復模型、肌力趨勢圖表與智慧槓片速算。

## 🌟 核心升級亮點

### 1. 現場訓練工作表（Hevy Style Workout Sheet）
- **告別雜碎按鈕**：以動作為卡片單位，每組清晰標示 `組別 | 前次表現 (Previous) | kg | 次數 | 完成`。
- **經典打勾完成流**：
  - 點擊「✓」完成組：該行優雅反灰、手機微震動反饋。
  - **自動啟動頂部組間計時器**（倒數完畢語音嗶嗶聲 + 震動）。
  - 自動比對歷史紀錄，若突破個人最佳（PR）即刻觸發慶祝音效與通知！
- **組別類型快速切換**：點擊組號可切換 `1/2/3` 正式組、`W` 熱身組、`D` 遞減組、`F` 力竭組。
- **漸進超負荷教練提醒**：動作標題頂部自動顯示「💡 上次 80kg × 8 ➔ 建議突破：82.5kg 或 9次」。

### 2. 肌群疲勞與恢復儀表板（Fitbod Recovery Model）
- **人體主要肌群動態計算**：胸部、背部、腿部、肩部、手臂/核心。
- **科學疲勞衰減演算法**：根據距離上次訓練的經過天數與近 7 天累積訓練組數，動態計算恢復度百分比（🟢 100% 完全恢復 / 🟡 恢復中 / 🔴 疲勞）。
- **智慧排程建議**：自動分析「今日最佳就緒肌群」，推薦今日適合的主訓課表。
- **一鍵器材替代（Equipment Swap）**：深蹲架或臥推架客滿時，點擊「🔄 替換」，即時切換為同肌群的啞鈴或機械替代動作。

### 3. 進階數據視覺化（Analytics & Progression）
- **三大項估算 1RM 進步曲線圖 (Line Chart)**：切換深蹲、臥推、硬舉，視覺化見證肌力攀升。
- **每週各肌群總組數柱狀圖 (Bar Chart)**：直觀監控各部位組數，確保達到科學增肌 10~20 組區間。
- **個人最佳紀錄 (PR) 榮譽牆**。

### 4. 優雅的槓片與熱身抽屜（Quick Plate Sheet）
- 槓片計算機不再佔據主畫面空間，點擊卡片右上角「🧮 槓片」，底部無縫滑出抽屜。
- 顯示國際標準色槓鈴切面圖與 4 組漸進熱身組（空槓 ➔ 50% ➔ 70% ➔ 85%），點擊即可一鍵帶入。

## 📱 手機更新與使用方法

如果您先前已經將 IronLog 加入手機主畫面：
1. 在手機上打開 **IronLog**。
2. 下拉重新整理（或重開 App 一次），Service Worker 會自動下載新版本！
3. 若您推上了 GitHub，只需在電腦執行：
   ```bash
   git add .
   git commit -m "feat: upgrade to Hevy + Fitbod pro workflow"
   git push origin main
   ```
   GitHub Pages 會在 1 分鐘內完成部署。
